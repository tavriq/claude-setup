# Claude Code — готовое окружение

Глобальный конфиг Claude Code: правила поведения, субагенты, скиллы, хук слежения за контекстом.
Ставится в `~/.claude` одной командой. Обезличено — личные данные и проектная внутрянка вырезаны.

## Установка

```bash
git clone https://github.com/tavriq/claude-setup.git
cd claude-setup
./install.sh                  # спросит, как к тебе обращаться
```

Опции:

```bash
./install.sh --name Иван      # без вопросов
./install.sh --dry-run        # показать что будет сделано, ничего не трогая
```

Всё, что перезаписывается, сначала копируется в `~/.claude/backups/setup-<таймстамп>/`.
Если `~/.claude/settings.json` уже есть — установщик его **не трогает**, а кладёт рядом
`settings.json.from-setup`, чтобы ты смёржил руками.

Проверка после установки: запусти `claude`, набери `/skills` и `/agents`.

## Что внутри

```
CLAUDE.md              глобальные правила поведения (см. ниже)
agents/                6 субагентов
skills/                9 скиллов
hooks/context-warn.sh  предупреждение о разросшемся контексте
settings.json          модель, effort, permissions, хуки
install.sh             установщик с бэкапом
```

### CLAUDE.md — правила

Главное, что в нём есть:

- **Анти-поддакивание.** Claude обязан спорить, если считает тебя неправым, и по запросу
  мнения сначала искать контраргумент, а потом давать прямой вердикт. Лечит склонность
  модели соглашаться со всем подряд.
- **Plan → Do → Verify.** Любая задача = план, выполнение, проверка. Макс 3 итерации на фейл.
- **Авто-триаж сложности.** Мелкая задача → делает сам; средняя → параллельные субагенты;
  крупная/рискованная → предлагает полный workflow, но не запускает молча (жжёт лимиты).
- **Не выдумывать.** Не знает — говорит, что не знает.
- **Токен-гигиена.** `/clear` при смене задачи, ручной `/compact` на ~50% окна,
  MCP-серверы точечно (каждый стоит токенов в контексте).
- **Проверка результата** без ритуальных отчётов «Проверил: X ✓» — просто чинит молча.

Тон общения там неформальный («брат», «чо»). Если не твоё — поправь секцию
«Обращение и стиль общения» в `~/.claude/CLAUDE.md` после установки.

### Агенты (`agents/`)

| Агент | Зачем |
|---|---|
| `anthropic-docs` | вопросы по устройству Claude Code — отвечает по официальной доке |
| `research` | глубокое исследование с вебом, не засоряя основной контекст |
| `docs` | документация библиотек через Context7 MCP (нужен сам MCP, см. ниже) |
| `code-reviewer` | непредвзятое ревью кода без контекста |
| `reviewer` | то же для любого результата: текст, конфиг, план |
| `qa` | генерит тесты, запускает, возвращает результаты |

### Скиллы (`skills/`)

| Скилл | Зачем |
|---|---|
| `commit` | автокоммит + push в conventional commits |
| `council` | совет из нескольких субагентов с анонимной взаимной критикой — для крупных решений |
| `worktree` | git worktree вместо повторных клонов |
| `deploy` | ручной деплой через Docker + Git на любой сервер |
| `docker` | контейнеризация проекта |
| `ssh-connect` | SSH/SCP/rsync через expect — не виснет на промптах |
| `install-mcp` | установка MCP-серверов |
| `stop-slop` | вычистка AI-канцелярита из текста |
| `avito-api` | полная спека Avito API (объявления, чаты, доставка, реклама). Автор — Petr Alexeev, MIT, `skills/avito-api/LICENSE` |

`deploy` и `ssh-connect` читают параметры сервера из `.env` проекта
(`SERVER_HOST`, `SERVER_USER`, `SERVER_SSH_KEY`, `SERVER_PASSWORD`, `DEPLOY_PATH`).
Свои креды держи в `.env` проекта, в этот репо они не попадают.

### Хук `context-warn.sh`

На каждый твой промпт смотрит размер транскрипта сессии и, если тот перевалил ~80k токенов,
показывает подсказку «пора /compact или /clear». Сообщение видишь только ты, в контекст
модели не уходит. Порог меняется переменной `CONTEXT_WARN_THRESHOLD`.
Не нужен — убери блок `UserPromptSubmit` из `settings.json`.

### settings.json

Модель `opus[1m]`, `effortLevel: xhigh`, автокомпакт выключен (вместо него — хук выше),
разрешён `Bash(git *)` без подтверждений, звук по завершении ответа (`afplay`, только macOS).
Под Linux/Windows убери хук `Stop` или замени команду.

## Чего здесь нет

- **MCP-серверы.** Ставятся отдельно — см. скилл `install-mcp` (`/install-mcp`).
  Агенту `docs` нужен Context7: `claude mcp add --transport stdio --env CONTEXT7_API_KEY=... context7 -- npx -y @upstash/context7-mcp@latest`
- **Плагины** (статуслайн и прочее) — ставятся через маркетплейсы Claude Code, не файлами.
- **Никаких секретов** — ни токенов, ни паролей, ни ключей, ни внутренних хостов.
  Если что-то подобное здесь однажды появится — это баг, чини сразу.
